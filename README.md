# C++ Console Applications Collection

A collection of three console-based C++ applications demonstrating fundamental programming concepts, data structures, and object-oriented design principles.


## 🎯 Projects Overview

This repository contains three standalone C++ applications:

1. **Bank Management System** - A simple banking application with account management features
2. **Phone Book Management System** - A contact management system using hash table implementation
3. **Tic-Tac-Toe Game** - A classic two-player game

## ✨ Features

### Bank Management System
- ✅ Create new bank accounts
- ✅ Deposit funds
- ✅ Withdraw funds
- ✅ Check account balance
- ✅ Secure account management with encapsulation

### Phone Book Management System
- ✅ Add new contacts
- ✅ Search contacts by name
- ✅ Delete contacts
- ✅ Display all contacts
- ✅ Hash table implementation with linear probing
- ✅ Efficient collision resolution

### Tic-Tac-Toe Game
- ✅ Two-player gameplay
- ✅ Interactive game board
- ✅ Win detection algorithm
- ✅ Draw condition handling
- ✅ Input validation

## 🔧 Prerequisites

- C++ compiler (GCC, Clang, or MSVC)
- C++11 or later
- Standard Template Library (STL)

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/cpp-console-applications.git
cd cpp-console-applications
```

2. Compile the desired project:

```bash
# Bank Management System
g++ -std=c++11 bank_management.cpp -o bank_management

# Phone Book Management System
g++ -std=c++11 phonebook.cpp -o phonebook

# Tic-Tac-Toe Game
g++ -std=c++11 tictactoe.cpp -o tictactoe
```

## 🚀 Usage

### Running the Applications

**Bank Management System:**
```bash
./bank_management
```
Follow the on-screen menu to:
- Create an account
- Perform deposits/withdrawals
- Check balance
- Exit

**Phone Book Management System:**
```bash
./phonebook
```
Use the menu options to:
- Add contacts (name and phone number)
- Search for contacts
- Delete contacts
- View all contacts

**Tic-Tac-Toe Game:**
```bash
./tictactoe
```
- Player 1 uses 'X', Player 2 uses 'O'
- Enter row and column numbers to place your mark
- First player to get three in a row wins!
